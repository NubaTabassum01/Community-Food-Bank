## Project Description
Community Food Bank Management System is a very simple and basic Python application to manage family registration, stock of food items and food distribution process.


## Features
- Registration of new families with unique Family ID.
- Checking for duplicate Family ID.
- Validating family name and number of members.
- Adding food packs in food bank.
- Distributing food packs to registered families.
- Not allowing distribution when requested quantity is more than available stock.
- Viewing registered families and history of distributions.
- Showing remaining stock of food and total food packs that have been distributed.
- Handling invalid menu choice input.

--> Classes
# 1. Family
Class that contains information about families
- Family ID
- Family Name
- Number of Members

# 2. FoodBank
Class containing functions for performing different operations of food bank.
- Family Registration
- Stock Management
- Food Distribution
- Generating report

# Data Structure Used
- > List: For storing distribution history.
- > Set: For keeping unique Family ID records.
- > Tuple: For storing single distribution record.
- > Dictionary:  For storing registered family objects by using Family ID as key.
